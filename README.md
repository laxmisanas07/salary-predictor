# 🤖 Salary Predictor

A Machine Learning project that predicts salary based on **experience** and **age** using **Linear Regression**.

## 🚀 Tech Stack
- Python
- Pandas
- Scikit-learn
- Linear Regression

## ▶️ Run

```bash
pip install pandas scikit-learn
python predict_salary.py
```
